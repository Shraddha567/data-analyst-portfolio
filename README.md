# Data Analyst Portfolio

This repository showcases data analysis projects built with SQL, Python, Power BI, and Excel. It includes sales dashboards, HR analytics, SQL case studies, data cleaning scripts, and reporting work.

## Projects

- `project-1-sales-dashboard`: Sales dashboard analysis and insights.
- `project-2-hr-analytics`: HR analytics reports and visualizations.
- `project-3-sql-case`: SQL practice problems and case study solutions.
- `project-4-python-cleaning`: Python data cleaning and scripting examples.
- `project-5-excel-report`: Excel reporting and dashboard examples.

## Goal

Provide a compact portfolio of analytical work that highlights practical skills in data preparation, querying, visualization, and reporting.
