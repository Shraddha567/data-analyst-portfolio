In VS Code terminal, In VS Code terminal, run this and only this
python3 main.py

Confirm Python exists: python3 --version

Make sure we are in correct folder: pwd

Create alias (1-time fix)
* echo 'alias python=python3' >> ~/.zshrc
* source ~/.zshrc
Then run command for Output:
python main.py

Install Packages: 
python -m pip install pandas

Packages are of two types:
1) Builtin like "os" package
2) External Package which we install by the help of pip
Pandas is the External Package/ Modules Example
and we canuse Packages and Modules interchangeably

python -m pip install requests
On macOS:
python -m pip
python -m pip install
