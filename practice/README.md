
# Power BI Practice Files

This folder contains Power BI report files and supporting data tables used for Power BI practice and analysis.

## Contents

- `Sales.pbix` - Primary Power BI report file for the sales dashboard project.
- `sample.pbix` - Secondary Power BI report sample file.
- `customers-1000-creditlimit.csv` - Customer dataset with up to 1,000 records and credit limit information.
- `customers_with_creditlimit.csv` - Expanded customer dataset including credit limit values.
- `employees.csv` - Employee dataset used for staff-level reporting and analysis.
- `offices.csv` - Office location dataset supporting regional and branch-level visualizations.
- `orderdetails_updated.csv` - Detailed order line items with updated fields for analysis.
- `orders_updated.csv` - Updated orders dataset with order-level information.
- `products_final.csv` - Final products dataset used for product-level sales analysis.
- `sales_2019_January.csv` - January 2019 sales dataset.
- `sales_2019_February.csv` - February 2019 sales dataset.

## Purpose

These files are intended for:

- Building Power BI dashboards and reports
- Practicing data modeling, relationships, and visualizations
- Exploring sales, customer, product, employee, and office datasets

## Notes

- Use the `.pbix` files to open the reports directly in Power BI Desktop.
- The `.csv` files can be used as data sources for creating or refreshing Power BI reports.
- The folder structure is organized to keep report files and source datasets together for easy practice and review.
